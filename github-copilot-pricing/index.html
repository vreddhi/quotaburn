Usage limits

Agent mode, chat, code review, cloud agent and CLI consume GitHub AI Credits (1 credit = $0.01); credits vary by model. Allowance resets monthly. Completions and next-edit suggestions are unlimited on paid plans. Free: 2,000 completions + 50 chat requests. Past the allowance: set a paid-usage budget or switch to a cheaper model.
