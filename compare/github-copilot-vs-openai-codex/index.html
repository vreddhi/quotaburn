Limits

Agent mode, chat, code review, cloud agent and CLI consume GitHub AI Credits (1 credit = $0.01); credits vary by model. Allowance resets monthly. Completions and next-edit suggestions are unlimited on paid plans. Free: 2,000 completions per month plus limited chat and agent usage (no chat count published). Past the allowance: set a paid-usage budget or switch to a cheaper model.
