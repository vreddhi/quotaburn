FAQ

How much does prompt caching save?

Cached input is billed at a fraction of the normal input price, often 10x cheaper (e.g. GPT-6.1 Sol $2.00 vs $0.10 per 1M). Savings scale with your cache hit rate.

Which models have cached-input pricing?

Claude Opus 5.5, Claude Opus 5 (legacy), Claude Sonnet 4.6 (legacy), GPT-6 Astra, GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna, GPT-5.6 Sol, GPT-5.3 Codex, Gemini 4 Argon, Gemini 3.8 Flash, Gemini 3.1 Pro Preview, Gemini 3.5 Flash-Lite, Grok 4.7, Grok Build 0.1, Grok 4.3. Models without a listed cache price are excluded.

Does this include cache write costs?

No. Some providers charge extra to write to the cache; this calculator uses list input, cached-input and output prices only.
