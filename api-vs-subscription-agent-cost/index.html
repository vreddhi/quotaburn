FAQ

When is the API cheaper than a subscription?

When your monthly token cost at list prices is below the plan price. The table shows light, default and heavy workloads for every model we track.

Do plans have hidden extra costs?

Often past the allowance: Claude offers usage credits at API rates, Cursor bills third-party models at API price, and Windsurf and Devin bill extra usage at API pricing.

Does caching change the answer?

Yes. Cache hits cut input cost sharply, so the default workload assumes 60% hits. Try other rates in the caching calculator.
