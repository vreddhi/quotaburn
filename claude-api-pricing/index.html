Haiku 5.5: the 100K-token prompt threshold

Anthropic lists two price rows for Haiku 5.5. For prompts of up to 100K tokens it is $0.1 input / $0.5 output / $0.01 cache read per 1M tokens. For prompts over 100K tokens it is $0.5 / $2.5 / $0.05, 5x the input price.

For a sub-agent that does search, summaries or file triage, keeping each Haiku prompt under 100K tokens is the difference between $4.69 and $23 for the example month above.

FAQ

How much does the Claude API cost per 1M tokens?

Per claude.com/pricing (verified 2026-10-26): Fable 5.1 $10 in / $50 out, Opus 5.5 $4 / $20, Sonnet 5.5 $2 / $10, and Haiku 5.5 $0.1 / $0.5 for prompts up to 100K tokens.

What is Claude's cache read price?

Opus 5.5 $0.2, Sonnet 5.5 $0.1, Haiku 5.5 $0.01 (prompts up to 100K tokens) and Fable 5.1 $0.25 per 1M cached input tokens, at the 5-minute cache TTL.

Why does Haiku 5.5 cost more for long prompts?

Anthropic prices Haiku 5.5 prompts over 100K tokens at $0.5 input / $2.5 output / $0.05 cache read per 1M tokens, versus $0.1 / $0.5 / $0.01 for prompts up to 100K.
