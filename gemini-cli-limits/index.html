Usage limits

Gemini CLI + Code Assist agent mode share a quota: 1,500 requests/user/day (Code Assist Standard), 2,000 (Enterprise). One prompt can trigger several model requests. Otherwise metered per token via a paid Gemini API key. The old personal-Google-account free tier (1,000 req/day) is reported discontinued since June 18, 2026; the GitHub README still advertises it.
