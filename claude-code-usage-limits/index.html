Claude Code usage limits explained

Why you see “usage limit reached”, when it resets, and what each Claude plan actually buys.

Data verified 2026-10-13 from official pricing pages.

How the limits work

Usage resets on a rolling 5-hour session window; paid plans add weekly limits. Claude Code shares one usage pool with Claude chat. Pro = at least 5x Free per session; Max = 5x or 20x Pro. No fixed message count is published. Past the limit you can enable usage credits billed at standard API rates.

  • Rolling 5-hour window: your session allowance refills 5 hours after usage, not at midnight.
  • Weekly cap (paid plans): a second limit on top of the 5-hour window.
  • One pool: Claude chat and Claude Code draw from the same allowance.
  • Overage: optional usage credits at standard API rates.

FAQ

How long until my Claude Code limit resets?

Claude usage resets on a rolling 5-hour session window. Paid plans also have weekly limits, so you can be blocked for longer if you exhaust the weekly cap.

Does Claude chat use the same limit as Claude Code?

Yes. Claude Code shares one usage pool with Claude chat on the same account, so heavy chat use reduces what's left for coding.

How much more usage does Max give?

Anthropic describes Pro as at least 5x Free per session, and Max as 5x or 20x Pro usage. No fixed message count is published.

What happens when I hit the limit?

You can wait for the reset, or enable usage credits, which are billed at standard API rates.
