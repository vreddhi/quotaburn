FAQ

Is Codex cheaper than Claude Code?

At the $20 tier both cost the same (ChatGPT Plus vs Claude Pro). On the API, GPT-6.1 Sol ($2 in / $0.10 cached / $10 out) and Claude Sonnet 5.5 ($2 / $10, no cache price listed) have the same list price, but Sol's cached-input rate makes it cheaper for cache-heavy agent loops.

Which has better usage limits?

Both use a rolling 5-hour window on the $20 plan. OpenAI's Pro plans currently have no 5-hour limit (weekly limits may apply); Claude Max raises the allowance 5x or 20x.

What do the top plans cost?

Codex: Pro 100 ($100), Pro 200 ($200), Pro 500 ($500). Claude: Max 5x ($100) and Max 20x.
