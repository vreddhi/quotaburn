FAQ

What is the cheapest model for coding agents?

At list prices with our default agent workload, GPT-6 Luna is cheapest at about $4.69/month, followed by Gemini 3.5 Flash-Lite ($17) and Gemini 3.8 Flash ($35).

Why does cache pricing matter so much?

Agents resend the same context every turn, so most input tokens can be cache hits. Cached input is often 10x cheaper than fresh input.

Should I use the cheapest model for everything?

Usually not. Route easy work (search, summaries, boilerplate) to cheap models and keep frontier models for planning and hard debugging.
